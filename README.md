
# Kokoma's Student Portfolio Website

## Project Overview
This project is a responsive student portfolio and academic management website developed as part of the COS106 Introduction to Web Technologies course at Miva Open University.

## Features
- Home page with student profile.
- About Me page showcasing skills and academic information.
- Projects page displaying academic and practical projects.
- Academic Planner for managing tasks and deadlines.
- Contact page with form validation.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Key Functionality
The website includes responsive page layouts, interactive navigation, task management and contact form validation.

## Project Purpose
The purpose of this project is to demonstrate practical knowledge of web development and the application of HTML, CSS and JavaScript in building a functional student portfolio.
